# ReadPrune

**Readout-Guided Visual Token Pruning**

Project repository for ReadPrune (FRA-Q2), a training-free visual token pruning method for vision-language models.

## Status

This repository currently contains only this README. Source code and additional documentation are being prepared for a future release.

## 中文说明

ReadPrune（FRA-Q2）是面向视觉语言模型的免训练视觉 Token 剪枝方法。

本仓库目前仅提供项目说明，代码与更多文档将在后续更新中发布。
